# aibase
a work-in-progress playground to explore how one can use ai to build a front-end starter base for building static web sites

[View Demo](https://kccnma.github.io/aibase)

## Changelog

- **2026-11-19:** Added the wrapping `.cluster` layout pattern, with responsive Docs and Style Guide examples.
- **2026-11-19:** Added responsive `.split` and `.with-sidebar` patterns; the Docs page now reuses the sidebar layout.
- **2026-11-19:** Added the first complementary CSS layout pattern, `.stack`, with Docs and Style Guide examples.
- **2026-11-19:** Added responsive mobile navigation across the site, including keyboard support and a no-JavaScript fallback. Optional Playwright checks cover the navigation; see [the docs](docs.html#sitenavigation).
