Getting Started

Simple Base is a minimalistic HTML + CSS + JS base front-end starter for simple, bespoke static websites. It was created for students learning how to hand-code a basic front-end framework line by line.

No prior web design experience is required. There is no pre-processing, no command line, and no special software. All you need is a text editor and a browser.

Folder Structure

Your site folder is organized so page files live at the root, CSS partials live in css/, JavaScript lives in js/, and images and videos live in media/. 


sitename/
├── index.html
├── css/
│   ├── style.css
│   └── partials/
│       ├── global-variables.css
│       ├── global-resets.css

CSS Partials

Similar to SASS, this setup uses native CSS @import rules to combine modular partial files into a single css/style.css file:


/* TABLE OF CONTENTS / CSS PARTIALS */

/* ---------- SITE GLOBALS ---------- */
@import url('partials/global-variables.css');
@import url('partials/global-resets.css');
@import url('partials/global-colors.css');
@import url('partials/global-typography.css');
@import url('partials/global-media.css');
@import url('partials/global-helpers.css');

/* ---------- PAGE LAYOUT ---------- */
@import url('partials/containers.css');
@import url('partials/grid.css');

/* ---------- PAGE STRUCTURE ---------- */
@import url('partials/structure.css');

/* ---------- CONTENT COMPONENTS ---------- */
@import url('partials/ui-buttons.css');

/* ---------- ANIMATIONS ---------- */
@import url('partials/animations.css');

style.css is the only stylesheet linked from your HTML. Partial order matters: variables load first so every downstream partial can reference them.

Global Colors

Simple Base comes with a starter set of global colors defined as CSS custom properties (variables). Edit them in css/partials/global-variables.css to re-skin the entire site.

  • #eee Body Background
  • #222 Body Text
  • rgb(66, 118, 229) Links
  • rgb(33, 82, 188) Link Hover

/* GLOBAL VARIABLES */

:root {

    /* MAIN UI COLORS */
    --body-background-color: #eee;
    --body-text-color: #222;

    /* LINK COLORS */
    --link-color: rgb(66, 118, 229);
    --link-color-hover: rgb(33, 82, 188);

    /* DEFINE FONTS */
    --font-sans: system-ui, sans-serif;
    --font-serif: Georgia, 'Times New Roman', Times, serif;

    /* SET FONTS */
    --font-body: var(--font-sans);
    --font-headings: var(--font-sans);

    /* SIZING UNITS */
    --spacer-tiny: .5rem;
    --spacer-small: 1rem;
    --spacer-medium: 2rem;
    --spacer-large: 3rem;
    --spacer-jumbo: 4rem;

    /* BORDERS */
    --border-radius: 10px;

}

Container

A reusable .container div that stays fluid on small screens and is fixed at a configurable max width (--container-width: 1100px) once large enough. It centers horizontally with margin-inline: auto.


<div class="container">
    CONTENT
</div>

Media Queries

This base uses a mobile-first approach. Styles written outside of a media query target small screens by default, then larger screens are layered on top with @media (min-width: 768px). 


/* MOBILE FIRST: DEFAULT STYLES APPLY FIRST */

/* MEDIUM / TABLET SCREENS AND UP */
@media (min-width: 768px) {
    /* LAYER ON THE GRID, LARGER TYPE, AND SITE LAYOUT HERE */
}

Animations

The main content area fades in on page load, and interactive elements (links and buttons) transition their colors smoothly on hover.


/* PAGE LOAD FADE-IN */
@keyframes fade-in {
    from { opacity: 0; }
    to   { opacity: 1; }
}
main {
    animation: fade-in .5s ease-in forwards;
}

/* BUTTON & LINK HOVER TRANSITIONS */
a,
.button {
    transition: color .2s ease-out,
                background-color .2s ease-out,
                border-color .2s ease-out;
}

AI Base is a basic set of starter HTML, CSS, and Javascript created by a human, assisted by AI, and built for front-end developers and UX/UI designers that want to embrace AI to build custom static websites that are fast and accessible.
