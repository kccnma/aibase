AI Base

A human-guided, AI-assisted code base for building custom static websites.

AI Base is a basic set of starter HTML, CSS, and Javascript created by a humman, assisted by AI, and built for front-end developers and UX/UI designers that want to build custom static websites that are fast and accessible. It is simple, fully customizable, and supports convenient features such as CSS custom properties (variables) and native CSS nesting.

No Build Tools

No dependencies. No compiling. No headaches. AI Base is all about straight up vanilla HTML, CSS, and Javascript. All local. Designed to stand the test of time and never break.

Less Opinionated

AI Base gives you just enough styling out-of-the-box to look good, yet remain 100% fully customizable. To layout content you will need a grid — we give you a solid one — along with a selected set of other helpful goodies.

Simple & Easy

Get started fast by cloning the repo or downloading it as a zip file. AI Base is designed for front-end devs that want to embrace AI and understand and manage every line of code.

Keep it Simple

Only the Bare Essentials

AI Base aims to provide only the core ingredients you need to build bespoke static websites, such as minimal base-level global CSS styling (a few common resets, a short set of helpful variables, minimalist typography settings, etc.) and essential layout tools to build responsive websites (a container and a semantic 12-column grid system).

A Solid Foundation

A Core Set of Building Blocks

AI Base provides a solid base-level of code upon which front-end developers and UI designers can build bespoke static websites, such as structural site components (site header, site footer, site nav, hero sections) and content components (buttons, type blocks, icons, block quotes, etc.).
